# George Mamalis — Personal Portfolio

Personal portfolio website for George Mamalis, a Computer Science student at the Hellenic Open University with an interest in software development.

## Preview locally

Open `index.html` in any modern browser. This static site does not need a build process, account or external dependencies.

## Publish with GitHub Pages

1. Create a GitHub repository. For a personal home page, name it `YOUR-USERNAME.github.io`, replacing `YOUR-USERNAME` with your actual GitHub username.
2. Upload `index.html` to the repository root.
3. Under **Settings → Pages**, select **Deploy from a branch**, then `main` and `/(root)`.
4. After publishing, open `https://YOUR-USERNAME.github.io/`.
5. Add the public link to your LinkedIn **Featured** and **Contact info** sections.

## Update before sharing

- Verify that the job title, work dates and listed responsibilities are correct.
- Add a contact email or GitHub link once you are ready to share it publicly.
- Replace planned-project entries with links to actual work as you complete it.
- Update project descriptions when you can discuss and demonstrate the code yourself.

## Built with

HTML, CSS and JavaScript. The site is responsive and includes a mobile navigation menu.
